# ♠ Poker Chip Counter

Contatore di chip per le partite di poker tra amici. Un'unica pagina HTML, nessuna installazione.

**Live:** https://poker-chip-counter.pages.dev

## Come funziona

1. **Setup** – imposta i colori e i valori delle chip, quante chip di ogni colore riceve ogni giocatore e i nomi dei giocatori.
2. **Distribuisci** – ogni giocatore parte con lo stesso stack.
3. **Ogni mano** – tocca le chip per puntare (o usa *Vedo* / *All-in* / *Passa*). Il piatto si aggiorna da solo.
4. **Fine mano** – seleziona il vincitore (🏆) e premi *Assegna il piatto*. Con più vincitori il piatto viene diviso.
5. **Classifica** – mostra stack e guadagno/perdita di ciascuno. *Ricarica* aggiunge uno stack a chi resta senza chip.

C'è anche *Annulla* per correggere un errore. I dati restano salvati nel browser del telefono che tiene il conteggio.

## Deploy

Il sito è un solo file (`index.html`): caricalo su Cloudflare Pages (Upload assets), GitHub Pages o qualsiasi hosting statico.
